Privacy Policy

Last updated: November 4, 2026  ·  Applies to: video_pub (TikTok Content Posting integration)

01Who this covers

video_pub is a single-operator automation tool: it connects to exactly one TikTok account, controlled by its developer, to publish that same person's own video content. It has no other users and collects no data about anyone else.

02What it accesses

DataWhy
TikTok OAuth access & refresh tokensTo authenticate upload requests to the authorized account, per video.publish / video.upload scopes
Video files & captionsSupplied directly by the operator, sent only to publish that exact post

No TikTok profile data, follower lists, analytics, or content belonging to other accounts is ever requested or read.

03Where it's stored

OAuth tokens are stored only in a local file on the operator's own machine, readable only by that machine's owner. Nothing is sent to, or stored on, any third-party server beyond TikTok's own API.

04Sharing

Nothing is sold, rented, or shared with any third party. The only network calls this tool makes are directly to TikTok's API endpoints, to publish content the operator has chosen to publish.

05Retention & revocation

Tokens persist locally until manually deleted. Access can be revoked at any time from TikTok's own connected-apps settings — this immediately invalidates the tool's access.

06Changes

This policy may be revised as the tool's scope changes. The "Last updated" date above reflects the current version.
